## 阶段 1：验收对象与要求纠正

原来本轮所有测量共用最严限制，标题数量与方向数量可能互相污染；误解要求无法纠正；已测文稿保存后，最终状态话术也被当成文稿检查。现在按回复部分、文稿或真实资产版本分别检查；误声明须关联同对象最近一次测量、本轮用户原话和纠正理由。通过的准确正文可以保存并独立回答状态，失败或正文变化仍拒绝。文稿检查成功但未保存、已保存作品检查失败都不能靠状态回复绕过。

边界：原话真实不证明语义解释正确；Agent 仍负责识别全部要求、划分交付项和保持目标身份。没有声明的要求、把多项误归为一项，不能被程序可靠发现。多个命名回复片段的检查证明原文包含关系，不证明全部附加内容也合规。

## 阶段 2：原稿传递与摘要压力

已有文稿修订允许使用准确父资产与版本，不要求在工具参数再次重抄父稿；聊天原稿仍需真实消息及准确正文片段。父关系回执保留完整正文，原文与历史不删除。摘要阈值改为固定系统/目录/工具成本加可压缩历史空间的比例，避免目标低于不可压缩底座。模型仍须实际读取原稿并核对父稿回执；ID/版本一致不能证明选中了用户想改的稿。

## 阶段 3：观察与生成的真实输入

观察遇到关联文字资料而没有明确选择时，返回候选资料身份，由 Agent 选择必要正文或明确说明不相关；不自动混入同批另一产品资料。已选择的来源读取实际存储正文并保留未知项标注。图片只登记在来源关系但没有绑定为真实视觉输入时，方案准备拒绝；回执显示实际视觉来源及版本，文字来源明确标为关系记录，必要内容仍须写入生成参数。

边界：不能识别 Agent 完全遗漏的图片义务或所有相关资料；无法以参数检查证明真实观察正确、未知事实没有被升级、成品保持合格。
