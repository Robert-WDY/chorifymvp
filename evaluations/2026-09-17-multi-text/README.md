- 43轮均有最终文字回复，未发生HTTP失败、超时或模型无返回。此为串行小样本，不代表并发/长期稳定。
- 3组出现6条工具错误反馈：4条single_tool_call_required（2组双调用被整体拒绝）、1条original_content_mismatch、1条invalid_edits。前者恢复；错误保存参数分别通过重试或改为聊天回答结束。

- 工具成功不等于用户任务成功：保存文稿实际含额外版本或虚构性能，须直接审正文。

## 修复优先级（本轮未实施产品修复）

1. **事实在下游继续保持身份**：商品参数未知时，具体性能句、使用体验和画面承诺均需依据；不以是否出现某个功效词代替语义验收。重点复测护手霜与磨豆机。
2. **当前交付总范围**：一版文案不扩为多版本或整套投放包；按实际最终正文核对句子和版本数，测量后不再追加。
3. **原稿作品边界**：保存聊天稿时选择作品片段并保留父消息关系；验收保存全文，不能只展示干净摘录。
4. **上下文约束保留适用对象**：摘要区分长期客户事实、某轮版式要求、当前任务，避免旧局部限制自动变为全局规则。
5. **工具协议和反馈解释**：避免多调用整组拒绝；聊天文本可绑定父消息，参数错误不应被解释成系统不支持。
