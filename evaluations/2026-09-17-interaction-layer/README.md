## 原因与分阶段结果

1. **会话与方案呈现**：原来的恢复异常分支直接新建会话，把网络失败变成上下文切换；方案回执只更新内存，等结束才渲染。现在保留原 session ID，区分不存在、无权限和连接错误，提供重试/明确新建；收到方案立即建卡。运行尚未结束时卡片可核对，批准按钮等本轮结束可用。
2. **公开活动**：此前页面主要展示消息，缺少可重建的执行活动。复用现有 `run_event`、NDJSON 和持久记录，增加稳定事件 ID、原始记录序号、真实时间、执行耗时和结果摘要；同一调用更新同一卡片，游标分页恢复。前端会话接口不再导出完整模型请求、原始工具结果、摘要或内部调用账本；完整 Trace 留在原存储/导出接口。公开错误掩码针对常见 Bearer/sk 格式，不宣称是通用秘密检测器。
3. **必要提问与暂停**：新增原生 `request_user_input`；问题快照保存在一次工具回执里，答案保存为下一条真实用户消息。无人回答不继续调用；部分回答跨重启保留且零模型调用；完整回答或关联的自由文字回到主 Agent。拒绝与取消分别记录。选项可绑定实际资产版本/方案 ID；选项和选中资产必须属于当前会话。问题输入不构成媒体批准，即使模型误调用确认工具也被执行层拒绝。
4. **工作区信息**：新增原生 `inspect_workspace`，返回服务端验证的选中资产、当轮附件、实际注册工具、媒体模式及可读入口。供应商健康和余额没有查询接口，明确返回未知。前端勾选经服务端校验后才进入真实用户消息和下一次模型输入。工具没有替 Agent 规划，也没有自动观察图片。
5. **有条件的真实文字流**：两个现有适配器增加 Responses SSE 读取器。仅显式声明支持且有公开文字回调时启用；默认 `LLM_TEXT_STREAMING_SUPPORTED=0`。公开文字增量可展示，推理字段和参数分片不展示、不执行；收到完整完成响应并通过协议、工具 Schema、单调用策略后才执行。截断/错误拒绝执行，片段标记未完成；最终只有工具调用而无完整文字时也不永久显示生成中。摘要保持非流式。本阶段只验证本地协议替身，线上兼容性未验证、未开启。

准备、发布、渲染、阅读是不同事实：工具保存方案表示**已准备**；持久 `proposal_published` 表示**服务端发布**；DOM 插入后上报表示**客户端报告已渲染**；**人是否阅读未知**。旧 `displayed` 字段仅保留兼容别名，不能当作人已阅读的证明。不增加已读点击门禁，实际提交仍需批准具体冻结方案。

断线或刷新只停止页面接收，服务端已开始的有界运行继续；刷新读取同一运行，不能自动重发请求。显式取消仍可停止运行。这不是后台任务调度或自动回答问题，结构化问题发布后本轮明确暂停。

动态发现与通用 `open_resource` 未新增：当前工具量有限，用户方案中属于按收益扩展项。真实素材仍可在现有素材面板查看/打开；不存在的控制台、余额或健康工具没有注册。没有强制先搜索工具。

- **已验证**：离线协议、Schema 与副作用边界，以及真实浏览器 DOM/网络/持久状态/后续脚本模型输入的一致性。
