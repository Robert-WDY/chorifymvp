# 2026-09-17 Debug 中间过程页面

基线ad119c9；同一chorifymvp-git、3217与会话数据。入口 http://127.0.0.1:3217/debug ，聊天页顶部“Debug 中间过程”携带当前session打开。也可在Debug中搜索、分页选择会话。

## 页面内容

- 会话总计：主Agent、摘要、视觉分别计数，工具选择、失败和未执行分别显示。
- 轮次及时间线：原始用户输入、模型请求与返回状态、工具调用、系统观察、批次执行规则、摘要/交付检查/开始结束等实际事件。
- 模型详情：保持原始消息顺序；系统提示词按段落，服务端数据按Skill索引、素材目录、原消息身份、历史裁剪等字段分块，用户消息和工具反馈单独保留。工具定义按工具展开。可查看预算/保留/裁剪指标、用量、实际输出或错误、完整原始JSON。
- 来源：输入保留的记录ID可直接回读；素材ID按实际结构字段精确匹配，不按子串猜测。出现ID仅表示输入包含它，不证明Agent读取或采纳。图片可主动加载实际引用URL，不把URL当视觉结果。
- 工具详情：实际arguments、原始结果、关联主Agent调用。系统规则记录明确是固定副作用分类，不是假造语义推理。
- 自动3秒刷新索引，详情按需加载，不每次拉全量模型输入。旧格式会话可导出完整档案，当前时间线不伪造旧版不存在的字段。

请求详情是应用传给模型适配器的输入，非供应商HTTP抓包；供应商序列化参数和模型隐藏推理未记录。次数按持久请求记录计数，不能代替供应商计费。协议拒绝的已收到输出现在写入model_error便于查看；网络未返回内容时仍无输出。没有改变决策、批准、Schema或业务路由；新增的执行规则为run_event，不加入模型上下文。
