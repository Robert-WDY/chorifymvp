## 修复总结

| 问题 | 发生位置 | 解决方案 | 证明 |
| -- | -- | -- | -- |
| 输入组装步骤显示了后来产生的回复，容易误以为回复来自输入阶段 | 共享模型记录与详情展示之间 | 按所选步骤区分输入和输出；输入节点只展示输入，并链接到后续Agent决策 | 专项证明输入页无后续回复，决策页可查看该回复；原始请求与响应均保留 |
| 系统段落、工具定义和历史工具结果重复展开，信息零散 | 模型输入阅读视图 | 系统指令合并成一个折叠项，工具定义和历史返回不在输入面板重复列出；结果仍在对应工具步骤与原始证据中 | 专项证明系统组只有一个、工具重复正文不出现；没有改变模型收到的提示词或裁剪持久数据 |
| 默认跳到最后一轮，用户看不到当前回复承接了什么 | 会话选择与多轮展示之间 | 主区按时间展示各轮用户要求与Agent公开文字，标明当前轮次；默认从首轮开始，可切换并打开完整原文 | 脚本验证两轮分离、前后文字与默认首轮；本机21轮42条消息预览与原始导出逐条一致 |

“工具反馈”指工具实际运行或被拒绝后返回的结果，不是可选工具清单。本轮仅去除输入面板重复展示，工具处理链、失败送达检查和原始证据仍保留。
