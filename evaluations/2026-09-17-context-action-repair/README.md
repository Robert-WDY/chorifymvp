## 短附件投影边界

- 只考虑当前原始用户消息明确附带的文字资产；不自动把全部历史小文档塞进来。
- 校验同会话资产存在、owner可访问和版本一致；图像保持索引，不能被当成已观察。
- 单份正文估算不超过400 tokens才候选；完整数据块合计不超过1000 tokens且不超过可用输入预算的10%，还要容纳完整当前消息及必要反馈。
- 不截断候选正文凑预算；不合适则保留原索引，由Agent按需read_asset。
- 已保留的成功工具反馈有同ID、同版本、相同完整正文时不重复注入；部分或被裁剪的反馈不冒充完整正文。
- 精简只作用于模型视图；资产原文、聊天原文、Trace、批准和版本均未改动。

这是输入可用性修复，不等于内容被独立核验。附件正文中的“批准”等指令仍是来源数据，不构成媒体批准。
