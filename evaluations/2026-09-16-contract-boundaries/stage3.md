# 阶段三：事实身份与实际内容验收

独立前序：987b85e。

- 从现有请求 facts、assumptions、factual gaps 与真实来源生成 factBoundary 投影，不增加可写事实数据库或摘要模型。user_provided 不等于独立核实；来源的 model_claim、unknown、unconfirmed 和 assumption 不因保存或被选中升级为事实。
- 来源、生成输入和产物元数据携带事实身份；带 sourceId/version/contentHash。模型视图对完整重复的事实身份使用同一请求内可读取的指针，持久资料仍完整保留。
- delivery_only 在存在事实或派生文字资料时调用已有 Verifier 的 verify_facts 范围检查，检查实际正文中的业务承诺。strict 复用原有文字验收，同时使用相同事实边界规则，不加第二次总审查。
- 拒绝或未核验不能完成；记录实际输出 hash、边界 hash、来源版本、验收范围。事实检查通过不等于事实独立核实，也不等于视觉或整体创作质量通过。
- Brief/文案 Skill 正文与生成系统说明同步，明确未知项可省略或保留限定，笼统免责声明不能抵消正文承诺。

独立验收：新增事实测试 7 项；最终全量 751/751，320 文件语法/独立性通过。阶段二另补 1 项渲染守卫：body/title 专用结构不能用未展示的 shots 元数据通过镜头验收。原阶段二记录保持不覆盖。

真实模型/媒体调用均为 0。旧 case 05/06 的实际内容已送入离线模拟验证器，证明拒绝结果不能被执行器覆盖；不能据此声称真实模型已识别这些错误。新增模拟链路检查失败后仅修复文案，Brief 与来源版本保留，unknown 身份持续传递。

副作用：delivery_only 对有事实或派生资料的每个文字候选增加一次限定范围的模型检查，格式无效可按原机制再试一次；拒绝时保留原两次生成候选上限。延迟和实际模型用量会增加，但本轮离线运行没有消耗真实额度。strict 不增加独立事实审查调用。

未验证：真实模型的误报/漏报率；新增模型成本；实际视觉质量。普通无事实的创作不增加检查。没有支持所有混合版式：同时要求 body/title 专用字数结构与镜头结构时，不会伪称隐藏镜头已经交付，当前需另行扩展可核验渲染方式。

未修改调度并行度、批准粒度、后台恢复或线上服务。回滚本阶段使用独立 git revert；已保存 Trace、事实原文和版本不删除。
