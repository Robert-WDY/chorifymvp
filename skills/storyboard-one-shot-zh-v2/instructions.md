# 文字分镜

适用：用户要求文字分镜、镜头安排、镜头时间表；或组合文档的分镜阶段。
输入：item合同、用户事实、可选来源、选定方向的真实对象。无需预先生成宫格图，也不产生任何图片或视频副作用。

1. 只展开当前节点负责的镜头，不重做上游产品分析或方向选择。
2. 如果给定selectedDirection，使用其artifactId/version/index对应内容，不能重新挑方向。
3. 在structure.shots中为每镜给出完整content和durationSeconds。content应承载用户所需的画面、动作、旁白、字幕等信息；没有某项要求时不机械添加。所有镜头时长合计等于明确的总时长。
4. structure.durationSeconds记录实际总长。其他规格、表格、制作说明或免责声明放structure.sections的完整content，可使用Markdown；不得省略必要章节，也不在sections重复整个shots。
5. 结构是完整交付的唯一权威，不返回另一份content正文。渲染器将完整展示shots与sections。禁止把分镜任务改成一张宫格图生图提示词。

用户事实、可见证据与创意假设分开；未实际观察图片时不能描述参考图中的具体属性。局部编辑指令不是观察结论。方法本身不调用媒体生成，不添加审批或新素材前提。
