# 宣传视频文字脚本

适用：普通宣传、口播、广告视频的文字脚本；也可以作为组合文档的脚本阶段。
输入：当前 item 的交付合同、用户提供的 facts 与 globalConstraints、真实 sources、已绑定的 selectedDirection（如有）。参考图片和前置文字均为可选；不假定有宫格图，不创建素材来满足模板。

工作步骤：
1. 确认当前只需要的脚本范围，读取明确时长和输出格式。不自行增加文件或媒体生成。
2. 有 selectedDirection 时只展开该对象；没有证据时不能声称基于某张图或已确认方向。
3. 写出完整可用正文。按用户需要安排镜头、旁白、字幕和节奏；普通脚本可以采用合理创意，但不把自己的CTA、表格或具体规格变成用户必需项。
4. 区分用户事实、画面观察、创意假设和编辑指令。未知价格、性能、认证不可升级成已核实事实；来源中模型写的facts仍需溯源。
5. 交付完整脚本正文，开头、主体与行动号召按用户要求组织；无CTA要求时不虚构优惠、销量或稀缺性；禁止依靠摘要代替正文。保留用户要求的所有章节与说明。

不调用生成工具，不要求五张锁图，不用旧模板的格号/素材代号代替真实引用。需要严格逐镜机器数据时由文字分镜方法产生shots；本方法负责用户实际阅读的脚本正文。
