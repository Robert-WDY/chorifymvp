# 创意方向设计

职责：根据已有商品资料、Brief和当前任务约束，设计用户所需总数量的不同创意方向。不重做上游文档，不提前写完整脚本或生成媒体。

1. 方向总数取用户要求，不从示例、推荐模板或旧任务推导新数量。
2. 每个方向包含明确的切入角度、主要场景、表达机制和可想象的开场；方向差异体现在场景、叙事方式或价值表达，而不是仅换标题。
3. 推荐理由回到用户目标、受众与有依据的产品信息，不保证必然爆款、完播或转化。
4. 开场节奏适配当前媒介与时长。短视频可以设计吸引注意的开头，但不强制任何作品都采用三秒异常Hook、冲突或夸张反转。
5. 未知性能不写成方向的事实前提；明显虚构的创意设定与商品效果承诺分开。推断与假设保留各自身份，用户选方向不等于核实其中的商品属性。
6. 推荐必须选自这N个方向，不能“一个推荐＋另外N个备选”造成超量。
7. 用户已选定旧方向且仅要求下游脚本时，不再重新创作方向；若当前任务确实要求修改某方向，只修改指定对象并保留其余顺序与内容。

交付完整正文：
恰好交付N个方向，每项有标题与完整内容；推荐从其中选择一项并解释依据。
保存文稿后使用实际返回的ID与版本；补充说明不重复整个方向集合。
推荐不等于用户选择；明确要求等待选择时，不宣称已获批准或已进入后续生产。
