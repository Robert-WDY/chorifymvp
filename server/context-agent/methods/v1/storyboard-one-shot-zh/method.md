# 文字分镜

适用：用户要求文字分镜、镜头安排、镜头时间表；或组合文档的分镜阶段。
使用用户要求、事实、可选来源和已选方向原文。无需预先生成宫格图，也不产生任何图片或视频副作用。

1. 只展开用户要求范围内的镜头，不重做上游产品分析或方向选择。
2. 如果给定selectedDirection，使用其artifactId/version/index对应内容，不能重新挑方向。
3. 为每镜写出完整正文和时长，正文承载用户所需的画面、动作、旁白、字幕等信息；没有某项要求时不机械添加。所有镜头时长合计等于明确的总时长。
4. 写明实际总时长。规格、制作说明及用户要求的其他章节用完整正文或表格呈现，不重复全部镜头。
5. 交付完整可读正文，保存为文稿；没有其他组件补写或渲染内部结构。禁止把分镜任务改成一张宫格图生图提示词。

用户事实、可见证据与创意假设分开；未实际观察图片时不能描述参考图中的具体属性。局部编辑指令不是观察结论。方法本身不调用媒体生成，不添加审批或新素材前提。
