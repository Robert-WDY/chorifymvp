# 导演多宫格分镜方法（合同版本 3）

本方法仅适用于一张包含全部选中镜头的整版故事板（storyboard_sheet）。
用户要求逐镜独立图片时，由运行时选择兼容方法；本方法不得改变文件数或删减镜头。
这里只规划内容，不调用媒体工具，不决定审批或重试。实际提交和结果查询由运行时负责。

## 输入和来源

使用运行时 sources 和 sourceSelection 绑定的真实来源、版本及镜头单元。
已有脚本时保留选中镜头的事件顺序、人物关系、动作、台词和连续性；不得增加或遗漏单元。
无源脚本且用户要求原创整版时，可以设计必要节拍，但格数须符合当前合同。
只使用运行时给出的参考图和观察证据，不编造URL、不根据文件名猜内容。

## 导演设计

确定戏剧冲突、角色信息差、情绪变化、空间位置、动作关系与光线连续性。
每格表现一个静态关键瞬间；使用适合该单元的景别、机位、焦段和视觉装置。
可参考 director-rules.md 与 visual-grammar.md 的导演分析；导演姓名不写为图片风格标签。

明确无人无字时，不因模板新增编号、台词或标题格。

## 整版布局

全部选中单元放在一个文件内，按来源顺序安排宫格。格数等于选中单元数。
列数与行数符合格数及比例；末行不满时居中，不添加空白、装饰、封面或标题格。
用户允许画面文字时，每格才可使用两位数编号与简短说明；用户要求台词逐字出现时原样保留。
统一人物身份、服装、道具、场景、时段、色彩与光线方向。

## 输出

按用户要求的格式交付完整故事板设计与提示词。
媒体规划仅编写一项包含所有选中单元的完整prompt；每格写明来源单元、构图、动作、景别、光线和连续性。
使用当前工具Schema中的size及referenceImages；不存在aspectRatio或refId等旧参数。
文字阶段按当前文档合同交付完整镜头及布局说明。

## 校验

核对选中来源单元与宫格逐一对应，没有遗漏、重复或合并。
核对画格数量、镜头连续性和文字；未运行的检查不得声称通过。
已加载、参数格式正确、单图内容验收、整体交付完成是不同状态，最终状态由运行时根据证据计算。
