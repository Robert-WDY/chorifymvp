# Chorify 上下文 Agent

这是独立的新入口。旧 `server/index.mjs`、compiled 执行器、旧会话和回归保持原样。新入口默认不调用真实模型，媒体默认 simulation。

## 启动

**本机隔离部署入口**：双击仓库根目录 `start-context-local.cmd`，访问 `http://127.0.0.1:3217`。它固定读取本仓库 `.env.local` 和 `data/isolated-local`，独立管理本实例进程，不使用下面通用入口的 `.env`、3212 或默认数据目录。[部署状态与验证](../../evaluations/2026-09-17-local-deployment/README.md)记录本次实际配置；以下通用启动说明仍保留。

在仓库根目录执行 `npm run start:context`，浏览器打开 `http://127.0.0.1:3212`。旧版仍通过 `npm start` 启动，默认端口 3210。两者不互相回退。

当前要求 Node >=22.13。新记录默认保存在 `data/context-agent/<owner-hash>/<session-id>.sqlite`，该目录被 Git 忽略。已有 JSON 在首次读取时迁移并保留原文件；完整 Trace 独立存储、按需读取，可导出完整会话。可以用 `CONTEXT_AGENT_DATA_DIR` 指定其他独立目录。当前 HTTP 是仅绑定本机的单用户开发入口，不是多租户公开部署服务；底层存取接口检查服务端 owner 身份。

真实模型需先取得授权、核对既有 `.env` 中的模型与额度，再显式设置：

```powershell
$env:CONTEXT_AGENT_ALLOW_MODEL = '1'
$env:CONTEXT_AGENT_MAX_MODEL_CALLS = '16'
npm run start:context
```

这只是启用说明，本轮没有执行这些授权设置。原模型 API 配置由 `createBrain` 读取，不另存一份凭据。`CONTEXT_AGENT_MAX_MODEL_CALLS` 是每轮请求上限，主循环、自动摘要及视觉观察共同计数，分别记录耗时、供应商返回的 usage 与费用（未返回则为未知）；它不是货币费用估算。重复真实评测另有跨用例共享总预算。

只有确认当前模型支持真实图像输入后，才可设置 `CONTEXT_AGENT_VISION_ENABLED=1`。这会注册实际图片观察通道；默认未注册时模型只能读取图片身份，不能声称看过图片。

真实媒体还需要显式 `CONTEXT_AGENT_ALLOW_MEDIA=1` 和正整数 `CONTEXT_AGENT_MAX_MEDIA_CALLS`；供应商配置存在时才注册对应能力。即使开启真实媒体，仍须在页面批准已展示的具体参数。首版没有自动后台推进；已有视频通过 `read_media_result` 查询。没有结果或无查询能力时保持未知，不自动重提。

## 模块职责

| 文件 | 输入与输出 | 负责范围 |
| --- | --- | --- |
| `loop.mjs` | 用户原话、会话记录 → 原生模型消息和调用 → 真实工具结果 | 循环协议、运行上限、取消、请求重放和完整 Trace；不解释需求或编译业务图 |
| `context.mjs` | 原始记录、资产目录、真实工具批准 → 当前模型视图 | 按估算 token 预算保留完整消息/工具组、附件标识和必要回读指针；不改持久原文 |
| `history.mjs` | 服务端 owner、会话 ID、原始记录 → 文件持久化/检索 | 原子写、角色顺序、原文检索分页、历史不可覆盖和会话隔离 |
| `tools.mjs` | 单次工具参数 → 文件、测量、观察或媒体回执 | 真实动作和可操作错误，校验实际素材类型；不安排业务步骤 |
| `io-guard.mjs` | 当前身份、精确方案和批准、调用身份 → 可执行范围 | 参数授权、额度、重复提交和提交未知保护 |
| `providers.mjs` | 已获准实际参数或真实图片输入 → 供应商结果 | 复用直接 ArkMedia 与图像模型接入，不创建旧任务对象 |
| `prompt.md` | 用户要求和工具反馈 | 一个主 Agent 的行为边界；没有旧需求合同/节点编排指令 |
| `http.mjs`、`index.mjs`、`web/` | 新建对话、文字资料/图片 URL、具体批准、取消 | 独立聊天入口，展示真实文件及来源；不启动旧引擎 |

会话保存 `records`、`assets`、`invocations`、`approvals`、`summaries`：实际消息/调用及系统执行反馈、不可变产物、提交回执、工具批准和有来源的派生摘要。摘要维护在 `memory.mjs`，共享确认执行在 `confirmation.mjs`，模型结果投影在 `result-view.mjs`；均复用现有存储与工具。`completed/error/cancelled/budget_exceeded` 仅表示一次模型运行怎样结束，不表示用户所有业务要求已经满足。

## 工具与历史

基础工具包括 `search_history`、`read_history`、`list_assets`、`read_asset`、`read_skill`、`save_document`、`measure_text`、`read_approval`、`confirm_media`、`execute_approved`。媒体按配置提供 `generate_image`、`edit_image`、`generate_video`、`read_media_result`，观察按能力提供 `analyze_image` 和显式双图 `compare_images`。服务与评测共用工具与摘要配置装配。

简单聊天创作、改稿可直接回复并保留原始对话，不强制存稿或重读当前完整原文。需要独立文稿、版本管理或修改已有资产时保存；聊天稿以 `parentMessageId` 和新正文一次保存原稿及修订。Skill 直接读取 `methods/v1` 专业正文，不使用旧节点执行协议。详见 [统一修复记录](../../FIXES.md)。

局部修订使用已有工具的 `edits:[{before,after}]`：文稿绑定 `parentId`，聊天稿绑定 `parentMessageId`，真实父版本自动取得；只取聊天中的作品片段时才提供 `sourceText`。不强制重抄原文或补版本声明；如果显式指定不存在的版本仍拒绝。在所选原稿上应用唯一、不重叠的准确片段替换，未涉及部分逐字保留。`after`可为空以删除片段，合成正文仍满足非空及长度限制。整篇重写保留`content`入口。读取时可带`forRevision:true`同收当前修改原话；长稿显式分页。

素材语义选择由 Agent 负责：检索历史和目录、读取实际内容、决定用户指向哪个素材。程序核对引用存在、可访问和类型；不根据标题或用户语义拦截合法选材。同批文字资料仅作为观察候选提示，不强迫使用；sourceIds是来源登记，实际视觉输入由referenceImages/imageId/firstFrameId决定，回执如实区分。错误选材通过真实评测定位，不新增语义拦截。准确片段能否应用、存档是否复制原文、用户隔离、批准和幂等属于执行完整性，继续保留。对照证据见[选材与提示词实验](../../evaluations/2026-09-17-revision-selection/README.md)。

已有媒体方案通过 `read_approval` 读取，使用同名准备工具和 `replacesProposalId` 加 `edits` 或需改参数做增量修订；未传参数继承，合成结果再通过完整 Schema。新方案重新展示批准，旧参数及来源保留；修改真实图片仍用 `edit_image`。保存文稿卡直接取持久资产正文，回执提供实际差异供 Agent 判断。程序不代替 Agent 判断父稿语义、改动范围或全部用户要求；详见 [增量修改证据](../../evaluations/2026-09-17-incremental-revision/README.md)。

编辑关系来自真实 `edit_image.imageId` / `save_document.parentId`，新文件记录父 ID 和版本；派生文件使用 `sourceIds`。图片生成的 `referenceImages` 是本会话图片 ID，创意文档可另用 `sourceIds`。原稿、未知项和原图不会因为上游文字存在而被自动替代。

每次主 Agent 响应最多执行一个工具，真实反馈进入下一次决策。意外多调用在副作用前整组拒绝，各调用均返回 `not_executed`，重试计入现有预算。只有明确确认的冻结媒体批次可以在一个工具内部逐项提交；一项失败、未知、取消或预算不足就停止余项。原子保存仍是一次操作。供应商声明支持时可设置 `LLM_PARALLEL_TOOL_CALLS_SUPPORTED=1` 发送真实 Responses 协议的 `parallel_tool_calls:false`；本批未核验线上供应商支持，默认不发送此选项。

媒体首次调用保存不可变方案，返回 `proposalId`。按钮按选中的 ID 直接进入共享 `approveAndExecute`，在首次模型调用前提交冻结参数；文字确认由同一个 Agent 选择 ID，通过仅接收 `proposalIds` 的 `confirm_media` 进入同一服务。授权绑定本轮真实用户消息；历史、引用、Skill 和摘要不能自己授予批准。否定、歧义或改参数应由 Agent 澄清/准备新方案，本批只验证程序边界，未验证真实模型的确认语义。`execute_approved` 留作已有批准的恢复入口；参数式兼容提交不向新 Agent 开放。

保存时冻结工具、默认参数、素材版本/内容身份、执行模式和供应商配置；展示顺序按需读取。被替代或撤回的方案不可确认。按钮产生 `system_observation`，没有伪造模型 callId；文件、回执和观察先保存，再由 Agent 回答。换请求 ID 或按钮/文字重复不会重复提交同一方案；未知结果先查询。基线的真实 `approval_required` 调用/结果对可恢复方案展示顺序；缺少冻结供应商身份的旧真实方案需重新准备并展示，不能继承新配置执行。撤回记录可识别，目前没有新增面向模型的撤回工具。

`analyze_image` 只观察明确指定的图片和资料，不自动扩展父图或同次附件。材料若含 `sourceId`，工具读取实际文字原文、版本和来源；可显式选择片段，超出观察预算会在外部调用前拒绝。模型写的内容及 `verified` 等标签仅保存在 `agentAnnotation`，不能覆盖原文。保持验收需用 `compare_images` 明确选择原图和成品。观察结果仍需主 Agent 判断，不能声称消除了模型事实错误。

`read_asset` 仅提示最多 8 个可访问父图/来源的身份，标记尚未读取，不递归获取正文。近期历史按完整工具组保留，长结果投影保留提交状态、回执、关键错误和准确回读指针。`search_history` 可按稳定原始序号从早到晚翻页；`read_history` 的目标、邻居和继续指针共同受返回预算约束。

每次裁剪前按完整输入组成检查压力，仅在需要时使用无工具的同配置模型压缩较早的完整连续记录；最新两轮用户对话和本轮明确指名的原记录受到保护。程序填写不可变原序号范围、源 hash 和摘要链；摘要不能批准媒体、替代原稿或冻结参数。超时、非法引用、过长结果或保存失败保留旧摘要与全部原文，同一失败源区间不反复重试。无法在摘要输入预算内容纳的巨大完整组不截断冒充全量摘要，退回普通上下文裁剪及精确回读。没有每轮必经摘要、跨会话画像或新数据库。

摘要默认开启维护，但仍受真实模型总开关与调用预算限制；默认配置为触发压力 0.75、目标 0.55、摘要 1800 估算 token、摘要输入 8000、每轮最多 2 次、保留 2 次主调用、安全余量 500。完整环境变量见根目录 `.env.example`。估算 token 不是供应商实测 token，实际摘要质量、线上耗时及费用仍待授权测试。

## 验证与回滚

### 原稿、摘要与交付验收（2026-09-17）

后续边界修复：索引、归档与修订统一使用完整文字消息；文字数组按原顺序以换行连接，来源范围基于这份文字，原消息不修改，混合媒体不静默过滤。同轮 requirements 从实际回执恢复并持续生效，重测不能放宽下限/上限、漏数量或改计数范围绕过；普通片段测量不声明最终要求，用户下一轮新要求重新识别。声明本身误解用户的风险仍待真实语义验证。最新结果及未闭环清单见 [遗留边界复查](../../evaluations/2026-09-17-remaining-boundaries/README.md)。

主 Agent 发起新的文本修订时，`save_document` 要求准确 `sourceText` 和父资产/消息 ID 同时一致。聊天原稿可选连续正文片段，来源范围保存在原有资产，完整原消息不改；资产父稿必须核对完整正文。回执 `parentEvidence` 提供实际父稿，不能只用标题推断。旧已完成调用仍可幂等重放；非模型直接调用保留兼容。简单聊天仍无需存稿。

摘要在现有完整预算内先预留引用与元数据，给出正文 UTF-8 字节目标；只有超预算才带实测反馈收缩目标重试，受原每轮摘要配额/总模型预算限制。摘要和下一次主调用收到有界真实资产证据，用于区分实际内容与助手标签；摘要语义仍由模型判断。

`measure_text` 可接收 `requirements`、`bodyText`、`items`，检查完整 draft 的声明数量及正文范围。最终文本须与本轮通过检查的 draft 相同；失败反馈交回同一 Agent 修正，不写成完成消息，耗尽原预算就停止。无硬约束聊天不强制测量；程序不从关键词另建合同，遗漏要求/错误语义分项仍需真实模型验收。

[本批分阶段验收](../../evaluations/2026-09-17-source-memory-delivery/README.md)：11 项专项、909 项全仓回归、历史证据回放及 11 项真实浏览器交互通过；真实模型/视觉/媒体未运行，不能据此宣称自然语义全部修复。

### 交互与公开活动（2026-09-17）

`interactions.mjs` 从原工具回执和真实用户消息投影问题状态；`public-events.mjs` 从现有 `run_event` 提供公开活动。没有新增业务任务状态系统。基础工具新增 `inspect_workspace` 与 `request_user_input`：前者查询实际选择/附件/注册能力（健康和余额保持未知），后者发布必要问题后暂停本轮。部分回答、拒绝、取消均不请求模型；完整回答/自由文字作为下一轮真实用户消息。内容选择不能授权媒体。

`GET /api/session/:id` 返回页面所需消息、素材、方案、问题及首批公开事件，不导出完整模型输入/内部 Trace；`GET /api/events/:id?after=N` 按原记录序号分页。`POST /api/answer` 接收真实回答；`POST /api/proposals/rendered` 仅记录客户端报告渲染，不授予批准。前端选择通过 `selectedAssetIds` 传入，服务器检查存在性和当前会话权限。完整原始记录仍由历史存储保留和导出。

方案保存、服务端发布、客户端报告渲染分别记录；没有记录“人已经阅读”的能力。旧 `displayed` 是兼容别名，实际表示发布。方案在后续模型回复结束前可见，本轮仍在运行时批准入口禁用。恢复失败保留 session ID 并提供重试，不自动新建；断开连接不取消已开始的有界运行，刷新通过游标恢复；只有明确取消停止运行，等待问题回答期间没有自动调用。

`LLM_TEXT_STREAMING_SUPPORTED=0` 默认关闭；取得授权并验证实际 Responses SSE 端点后才可开启。启用后只公开文字增量，推理/工具参数片段不公开；工具执行必须等待完整响应并通过既有检查。截断文字标为未完成，未完成参数不执行，摘要仍非流式。线上供应商流式尚未验证。未新增强制工具搜索或通用导航。

本批 [交互验收与回滚边界](../../evaluations/2026-09-17-interaction-layer/README.md)：离线 898/898、Agent 147/147；真实浏览器 11 项通过，使用脚本模型和模拟媒体，不能代表真实模型判断或媒体质量。旧版本不能继续新问题协议，回滚前必须保留当前完整数据并在独立副本检查兼容。

`npm run test:context` 运行独立离线测试。`npm run eval:context` 核对固定语料并报告真实语义测试未运行，不调用模型。

初版结果见 `evaluations/2026-09-16-context-agent/README.md`，当前证据及回滚步骤见 [统一本轮验收](../../evaluations/2026-09-17-unified-repair/README.md)。停止此入口后可使用旧 compiled 入口；新会话不得直接交给旧引擎运行，旧节点状态也不自动导入新路径。回退 context-agent 前应停止写入，完整导出最新会话，同时生成基线兼容副本；不能用过时 JSON 覆盖最新会话或让基线直接打开新 SQLite。

当前文件存储和进程内锁只保证单个本地服务进程的调用保护。没有分布式提交保证；供应商不支持幂等或缺少查询回执时，只能保留结果未知并阻止自动重提。
